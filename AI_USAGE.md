# AI Usage

## Tools Used

* ChatGPT
* Replit AI

---

## How AI Was Used

AI was used as a supporting tool during development, mainly for:

* Debugging specific Laravel errors
* Understanding certain concepts like request validation and routing

---

## Where AI Helped

* Basic CRUD structure for quizzes and questions
* Suggestions for improving validation logic
* Fixing syntax or runtime errors during development

---

## Adjustments and Corrections

AI-generated code was reviewed and modified:

* Adjusted logic for handling different question types
* Fixed issues in validation and request handling
* Refactored code to match the actual database structure


---

## Manual Work

The following parts were implemented and refined manually:

* Designing the overall quiz flow
* Structuring models and relationships
* Implementing multiple question type handling
* Creating the QuestionType system (interface + registry)
* Integrating attempts and answer tracking
* Testing and fixing runtime issues

---

## Key Learning

AI helped speed up development in some areas, but handling multiple question types and integrating them into a working system required manual design and iteration.

---

## Final Note

AI tools were used for assistance and learning, but the final implementation required understanding, modifications, and integration to make the system function correctly.
